# Mekorita

Mekorita (meaning "Collaboration" in Igbo) is an internal developer collaboration platform designed to streamline engineering workflows. 

This repository contains the frontend client, built with modern web technologies.

## Tech Stack
- Next.js 15 (App Router)
- React 19
- TypeScript (Strict)
- Tailwind CSS v4
- shadcn/ui & Radix Primitives
- Framer Motion
- Lucide Icons

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-org/mekorita.git
   cd mekorita
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
