# Contributing to Mekorita

Welcome! We are excited to have you contribute to Mekorita. This document outlines the process for contributing to this repository.

## Workflow

1. **Find an Issue**: Check the issue tracker for open issues. If you want to work on something new, please open an issue first to discuss it.
2. **Assign Yourself**: Comment on the issue claiming it so others know you are working on it.
3. **Branch**: Create a new branch following our [Branching Strategy](BRANCHING_STRATEGY.md).
4. **Develop**: Write your code, following our [Coding Guidelines](CODING_GUIDELINES.md).
5. **Commit**: Write clear, descriptive commit messages.
6. **Pull Request**: Open a PR against the `main` branch. Fill out the PR template completely.
7. **Review**: Address any feedback from reviewers. Once approved, a maintainer will merge your PR.

## Code Review Expectations
- All PRs must have at least one approval from a Senior Engineer.
- CI checks (linting, type checking, tests) must pass.
- UI changes should include screenshots in the PR description.
