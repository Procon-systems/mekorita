# Product Roadmap

This document outlines the planned features for Mekorita. These items will be broken down into GitHub Issues for contributors to claim.

## Phase 1: Foundation (Current)
- [x] Initial Next.js App Router setup
- [x] Authentication flows (Mocked)
- [x] Global layout and navigation
- [x] Design system and shared components

## Phase 2: Core Modules
- [x] **Notifications Center**: Real-time alerts and activity feeds.
- [x] **Task Management**: Personal task lists and assignments.
- [x] **Kanban Boards**: Drag-and-drop project boards (using `dnd-kit`).
- [x] **Global Search**: Command palette (`cmd+k`) for quick navigation.

## Phase 3: Advanced Features
- [x] **Documentation Wiki**: Rich markdown editor for internal docs.
- [x] **Insights Dashboard**: Engineering metrics and velocity charts (using Recharts).
- [x] **Settings & Preferences**: User profiles and workspace configuration.

## Phase 4: Polish & Experience
- [ ] **Interactive Landing Page**: Fully scroll-interactive landing page using `GSAP` and `Lenis` for smooth, cinematic scroll animations.
- [ ] **Dark Mode**: System-aware dark/light theme toggle with persistent user preference (using `next-themes`).
